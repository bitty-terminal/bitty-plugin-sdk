# Bitty Plugin SDK persona catalog

Use the narrowest persona that matches the task. The commander coordinates and
accepts evidence; specialists own API design, Lua ergonomics, compatibility,
documentation/examples, or verification. An author must not be the sole
independent reviewer of a material change.

- `commander`: task graph, scopes, dispatch, integration, and acceptance.
- `plugin-api-designer`: versioned host-to-plugin contract design.
- `lua-sdk-engineer`: Lua helpers, LuaLS types, mocks, and test ergonomics.
- `compatibility-reviewer`: host/SDK/plugin version and migration review.
- `docs-examples-maintainer`: verified plugin-author guidance and examples.
- `quality-engineer`: conformance, negative tests, and release evidence.

Every persona must obey repository `AGENTS.md` and applicable rules under
`.carryctx/rules/`.
